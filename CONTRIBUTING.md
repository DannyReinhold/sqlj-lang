# Feedback and documentation corrections

The plugin source repository is private. This GitHub repository contains generated
public documentation only; it cannot be used to build the plugin or submit source
patches. The publisher replaces its contents, so coordinate documentation changes
with the maintainer instead of editing the generated branch directly.

Send bug reports, feature requests and documentation corrections to
[support@sqlj-lang.org](mailto:support@sqlj-lang.org). Include exact versions,
reproduction steps and expected/observed behavior using the
[support checklist](docs/user-guide/troubleshooting.md). Do not publish customer
source, credentials or production data. Remain respectful in public discussions.

Source contributions require separately authorized access and agreement with the
maintainer. Do not assume public source access or commercial relicensing rights.
Documentation is CC BY 4.0; embedded examples and wizard output are MIT; plugin
code has separate PolyForm Noncommercial/commercial terms. See
[licensing](docs/licensing.md) for scope and third-party rights.
