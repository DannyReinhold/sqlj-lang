# Using the SQLJ plugin

Start with the task you need to perform:

- [Install and run the DB2 demo](getting-started.md).
- [Integrate the debug build tool into existing Maven/CI processes](build-tool-integration.md).
- [Set up editor assistance in an existing project](ide-features.md).
- [Check capabilities and limitations](compatibility.md).
- [Look up SQLJ forms and editor checks](language-reference.md).
- [Configure Java/Spring/Liberty debugging](debugging-project-types.md).
- [Exercise stepping, watches and breakpoint expressions](debugging-checks.md).
- [Troubleshoot or report a problem](troubleshooting.md).

If you provide IDEs and plugins to other developers, use the separate
[administration guide](../administration/deployment.md). Application development
does not require access to the private plugin repository. Tutorials explain
SQLJ constructs separately from the plugin's [implemented scope](compatibility.md).
