# SQLJ Language Reference

This reference covers the complete syntax, keywords, directives, and semantics supported by SQLJ and the IntelliJ plugin.

---

## 1. Directives & Statements

All SQLJ clauses begin with the `#sql` token and terminate with a semicolon (`;`).

### 1.1 Executable SQL Statement

Executes an arbitrary SQL statement (e.g. `INSERT`, `UPDATE`, `DELETE`, DDL, or stored procedure call):

```java
#sql { INSERT INTO department (dept_no, dept_name) VALUES (:deptNo, :deptName) };
```

Multiple lines are supported inside braces:

```java
#sql {
    UPDATE employee
    SET salary = salary * 1.05
    WHERE dept_no = :deptNo
};
```

## 2. Iterators

Iterators are strongly-typed cursor interfaces generated by the SQLJ preprocessor.

### 2.1 Named Iterators

A **named iterator** declares column names and their expected Java types. Column access methods match the declared column names.

**Declaration**:
```java
#sql public static iterator EmpIter (
    int empNo,
    String firstName,
    String lastName,
    double salary
);
```

**Usage**:
```java
EmpIter empIter;
#sql empIter = {
    SELECT empno AS empNo, firstnme AS firstName, lastname AS lastName, salary
    FROM employee
    WHERE workdept = :dept
};

while (empIter.next()) {
    System.out.printf("%d: %s %s - $%.2f%n",
        empIter.empNo(), empIter.firstName(), empIter.lastName(), empIter.salary());
}
empIter.close();
```

### 2.2 Positional Iterators

A **positional iterator** defines types by column ordinal position. Rows are fetched using `#sql { FETCH :iter INTO :var1, :var2 }`.

**Declaration**:
```java
#sql iterator PosEmpIter (int, String, double);
```

**Usage**:
```java
PosEmpIter posIter;
#sql posIter = { SELECT empno, lastname, salary FROM employee };

int empId;
String lastName;
double salary;

while (true) {
    #sql { FETCH :posIter INTO :empId, :lastName, :salary };
    if (posIter.endFetch()) {
        break;
    }
    System.out.println(empId + ": " + lastName + " - " + salary);
}
posIter.close();
```

## 3. Host Variables & Expressions

Host variables bind Java scope values into SQL statements.

### 3.1 Syntax Summary

| Form | Description | Example |
|---|---|---|
| `:varName` | Standard input host variable | `WHERE id = :id` |
| `:IN varName` | Explicit input parameter | `WHERE status = :IN status` |
| `:OUT varName` | Output parameter (stored procedures / callable statements) | `CALL get_bonus(:empId, :OUT bonus)` |
| `:INOUT varName` | Bidirectional parameter | `CALL adjust_rate(:INOUT rate)` |
| `:(expression)` | Parenthesized Java expression | `WHERE created > :(Instant.now().minusDays(30))` |

### 3.2 Complex Expressions

Any valid Java expression can be passed within parentheses:

```java
#sql {
    UPDATE orders
    SET total = total - :(discountCalculator.calculate(order.getItems()))
    WHERE order_id = :(order.getId())
};
```

## 4. Connection Contexts

SQLJ allows executing statements across specific database connections using connection contexts.

### 4.1 Declaring Custom Contexts

```java
#sql public context ArchiveContext;
#sql public context ProductionContext with (dataSource = "jdbc/prod");
```

### 4.2 Context Qualifiers

Prefix `#sql` with a context qualifier `[contextVariable]` to route execution to that specific context instance:

```java
ArchiveContext archCtx = new ArchiveContext(archiveConnection);

#sql [archCtx] {
    INSERT INTO archived_orders
    SELECT * FROM active_orders WHERE status = 'CLOSED'
};
```

## 5. Single-Row Query Assignment

Assign scalar SQL query results directly into host variables:

```java
int totalCount;
double avgSalary;

#sql {
    SELECT COUNT(*), AVG(salary)
    INTO :totalCount, :avgSalary
    FROM employee
    WHERE workdept = :dept
};
```

## 6. Type Mappings (DB2 SQL to Java)

| SQL Type | Java Type |
|---|---|
| `INTEGER` / `INT` | `int`, `java.lang.Integer` |
| `BIGINT` | `long`, `java.lang.Long` |
| `SMALLINT` | `short`, `java.lang.Short` |
| `DECIMAL(p,s)` / `NUMERIC` | `java.math.BigDecimal`, `double` |
| `VARCHAR(n)` / `CHAR(n)` | `java.lang.String` |
| `DATE` | `java.sql.Date`, `java.time.LocalDate` |
| `TIME` | `java.sql.Time`, `java.time.LocalTime` |
| `TIMESTAMP` | `java.sql.Timestamp`, `java.time.LocalDateTime`, `java.time.Instant` |
| `BLOB` | `java.sql.Blob`, `byte[]` |
| `CLOB` | `java.sql.Clob`, `java.lang.String` |
